# 连接 Google Sheet（一次就好）

1. 打开 https://script.google.com ，点「新项目」。
2. 删掉编辑器里原有的代码，把 `Code.gs` 全部内容贴进去，保存。
3. 上方函数选 `setup`，点「运行」，按提示授权（会说"未经验证"，点「高级 → 前往」即可，这是你自己的脚本）。
   它会建好「成长账本」表格，并开启每天 9 点的 Email 还款提醒检查。
4. 右上角「部署 → 新建部署」→ 类型选「Web 应用」：
   - 执行身份：**我**
   - 谁可以访问：**任何人**
5. 复制网址，打开 app：设置 → Google Sheet 同步 → 贴上 → 「连接并保存」。

改了脚本代码后：要「部署 → 管理部署 → 编辑 → 版本选新版本 → 部署」，网址不变。

## 功能说明

- **记录表**：每笔收支 / 转账，支持照片直接嵌入单元格。
- **目标 / 订阅 / 账户 / 定期**：自动同步到对应表，并显示在首页仪表板。
- **汇总页**：每日 / 每月 / 每年 / 分类汇总（自动计算）。
- **首页仪表板**：本月日历（带当日收支）、最近 12 个月柱状图、右侧账户/订阅/目标/定期面板。
- **邮件提醒**：每天 9 点检查还款日 / 订阅续费（可在 app 里开关）。
- **重建**：可手动在编辑器运行 `rebuild` 函数，或通过 API 发送 `{action: "rebuild"}` 刷新汇总与首页。

照片过大（> ~150KB base64）会自动跳过，避免表格卡顿。
